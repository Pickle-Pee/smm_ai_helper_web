# SMM AI Helper Web

Independent SaaS frontend for [SMM AI Helper](https://github.com/Pickle-Pee/smm_ai_helper).

Work in progress: the initial Next.js interface is being migrated to an isolated feature branch. No backend, Telegram, or AI orchestration code is included.

## Development

The planned frontend uses Next.js and TypeScript, with mock data until authenticated API v2 contracts are available.
